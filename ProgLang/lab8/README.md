*Рассмотрим программу на языке* **Python**.
```
x = [int(t) for t in input().split()]
for i in range(len(x)):

*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась
инструкция* **break**, *а используемый алгоритм не изменился. Полученная программа должна иметь следующий 
вид.*
```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор* **not**.

Программа на Python
```
x = [int(t) for t in input().split()]
i = 0
while i < len(x) - 1 and i <= x[i] <= 2 * i:
   i += 1
print(i)
```

Ввод и вывод: для 0 5 3 обе выводят 1.

Цикл for с break заканчивается на первом i, для которого выполняется условие выхода x[i] < i or x[i] > 2*i. В while условие нужно записать наоборот: цикл должен идти, пока условие выхода не выполняется. Чтобы получить отрицание без not, использовал правило де Моргана. Отрицание x[i] < i это x[i] >= i, отрицание x[i] > 2*i это x[i] <= 2*i, а or заменяется на and. Получается x[i] >= i and x[i] <= 2*i, в Python это можно записать цепочкой i <= x[i] <= 2*i.

Еще нужно следить за границей списка, иначе при i = len(x) будет ошибка IndexError. Если в исходной программе break ни разу не сработал, то после цикла в i остается последнее значение счетчика, то есть len(x)-1. Поэтому в while стоит условие i < len(x) - 1. Когда i доходит до len(x)-1, цикл останавливается, и выводится len(x)-1 при любом исходе и если для последнего элемента условие выхода выполнено, и если нет.

#include <iostream>

int main() {

}

```

В выводе (при 5 и 1 -2 3 -4 5) последний элемент равен 5, после добавления получается 6 3 8 1 10, поэтому вывод 5 0. (при 3 и -1 -1 -1) после добавления получается -2 -2 -2, вывод 0 3.

### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*

Программы на C++
```cpp
// Проверка работы с вектором и области видимости
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v(10, 1);
    int count1 = 0;
    {
        int __i = 0, __n = v.size();
        for (const int &i = __i; i < __n; __i++) {
            v.push_back(i);
            count1++;
        }
    }
    cout << "forc: итераций " << count1 << ", размер вектора " << v.size() << endl;

    vector<int> w(10, 1);
    int count2 = 0;
    for (int i = 0; i < w.size(); i++) {
        w.push_back(i);
        count2++;
        if (count2 == 1000) {
            cout << "for: остановлен принудительно на 1000 итерациях" << endl;
            break;
        }
    }
    cout << "for: итераций " << count2 << ", размер вектора " << w.size() << endl;

    {
        int __i = 0, __n = 3;
        for (const int &i = __i; i < __n; __i++)
            cout << i << " ";
    }
    {
        int __i = 5, __n = 8;
        for (const int &k = __i; k < __n; __i++)
            cout << k << " ";
    }
    cout << endl;
    return 0;
}
// Обычный for, где менять счетчик можно и раскрытый forc, где счетчик менять запрещено
#include <iostream>
using namespace std;

int main() {
    for (int i = 0; i < 10; i++) {
        cout << i << " ";
        i += 2;
    }
    cout << endl;

    {
        int __i = 0, __n = 10;
        for (const int &i = __i; i < __n; __i++) {
            cout << i << " ";
        }
    }
    cout << endl;
    return 0;
}


```

Первое различие в том, что граница to вычисляется один раз. В раскрытом коде to записывается в переменную __n до начала цикла, и условие i < __n сравнивает счетчик с этим сохраненным числом. В обычном for (int i = 0; i < v.size(); i++) выражение v.size() вычисляется заново перед каждой итерацией. Если тело цикла меняет размер вектора, циклы начинают вести себя поразному. В первой программе взял вектор из 10 элементов и в теле цикла вызвал v.push_back(i). В forc(i, 0, v.size()) граница 10 запомнена, поэтому выполняется ровно 10 итераций, и размер вектора после цикла равен 20. В обычном for с условием i < v.size() вектор растет вместе со счетчиком, условие всегда остается истинным, и цикл бесконечный. Чтобы программа все же завершилась, в нее добавлен принудительный выход на 1000 итерациях, при этом размер вектора 1010.

Второе различие в том, что счетчик i нельзя менять в теле цикла. В forc переменная i объявлена как const int &i, то есть это ссылка на скрытую переменную __i, и записывать значение через нее запрещено. Менять счетчик может только сам цикл через __i++, поэтому число итераций нельзя нарушить случайным присваиванием в теле. В обычном for счетчик это обычная переменная, и в теле ее менять можно.

Это видно на двух программах. Во второй программе обычный for с i += 2 в теле выводит 0 3 6 9, программа компилируется и работает. В третей программе такая же запись внутри forc не компилируется, выдает сообщение: error: assignment of read-only reference 'i'(присваивание ссылке i, которая доступна только для чтения)

Внешние фигурные скобки создают область видимости, и переменные __i и __n существуют только внутри этих скобок, после цикла они исчезают. Из-за этого две конструкции forc подряд в одной функции не конфликтуют по именам __i и __n, а сами служебные переменные нельзя случайно использовать после цикла. Без скобок второе объявление int __i в той же области видимости было бы ошибкой повторного объявления. В четвертой программе две раскрытые конструкции стоят подряд, программа работает и выводит 0 1 2 5 6 7.

*Написанные программы сохраните в папку с номером задания.*

Программа на Python:
```python
x = [int(t) for t in input().split()]
for t in x:
    if t < 0:
        print(t)
        break
else:
    print("Отрицательных чисел нет")
```
Ветка else у цикла выполняется только тогда, когда цикл закончился сам, без break. Поэтому сообщение об отсутствии отрицательных чисел выводится именно в этом случае.

Программа на С++:
```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<int> x;
    for (int i = 0; i < n; i++) {
        int t;
        std::cin >> t;
        x.push_back(t);
    }
    bool f = false;
    for (int e : x) {
        if (e < 0) {
            std::cout << e << std::endl;
            f = true;
            break;
        }
    }
    if (!f)
        std::cout << "Отрицательных чисел нет" << std::endl;
    return 0;
}

```

Появилась дополнительная переменная f, флаг. Перед break в нее записывается true, а после цикла по ней проверяется, был ли выход через break. Это нужно потому, что в С++ у цикла нет ветки else, и язык сам не отличает выход по break от обычного завершения цикла. Информацию о том, что break сработал, приходится запоминать вручную и проверять после цикла. Остальной алгоритм, то есть последовательный просмотр до первого отрицательного числа, не меняется. Программы для ввода 3 4 -5 6 -7 выводят -5, а для 1 2 3 выводят сообщение об отсутствии отрицательных чисел.

###  Задание 9 **(3)**
*Напишите программу на языке Python для решения следующей задачи.*

*Задана пронумерованная последовательность логических значений* **t(0),t(1),..,t(n)**, **t(i) ∈ {False,True}**

*Последовательность обладает следующим свойством: существует некоторое число k такое, что 
все значения* **t(0),t(1),...,t(k-1)** *равны* **False**, *а все значения* **t(k), ... , t(n)** *равны* **True**,
*то есть слева от* **k** *находятся значения* **False**, *а справа* - **True**. *Последовательность задается
функцией* **t(i)**, *которая возвращает логическое значение. Например, для тестирования эту функцию можно
задать следующим образом.*
```
def t(i):
   return i>=1000
```

*Требуется написать программу, которая найдет число* **k**. *Программа должна реализовывать алгоритм 
бинарного поиска. Диапазон поиска задается переменными* **left** и **right**. *На каждом шаге вычисляется
центр диапазона, значение в нем проверяется, после чего диапазон сокращается в два раза.*

*Алгоритм должен быть записан через цикл* **while** *и реализовывать инвариант цикла*

t(left)=False ∧ t(right)=True

```
left = -1
right = 10**18
while ...:
   mid = ...
   if t(mid):
      ...
   else:
      ...
print(...)
```

Программа на Python
```python
def t(i):
    return i >= 1000

left = -1
right = 10**18
while right - left > 1:
    mid = (left + right) // 2
    if t(mid):
        right = mid
    else:
        left = mid
print(right)
```

Для t(i) = i >= 1000 программа выводит 1000. Число k это номер первого значения True, поэтому в конце выводится right.

Инвариант цикла это утверждение, которое верно перед каждой проверкой условия цикла и после его завершения. В задаче инвариант такой: t(left) = False и t(right) = True.

Перед первой итерацией left = -1. Элемента с таким номером в последовательности нет, считаем, что слева от начала стоят значения False, поэтому t(left) = False. Значение t(10**18) = True берется из условия, то есть предполагается, что k не больше 10^18. На каждом шаге инвариант сохраняется. Если t(mid) истинно, то выполняется right = mid, и новое right тоже имеет значение True, а left не менялось. Если t(mid) ложно, то выполняется left = mid, и новое left имеет значение False, а right не менялось. В обоих случаях инвариант остается верным. Цикл заканчивается, когда right - left = 1. По инварианту t(left) = False и t(right) = True, а left и right стоят рядом. Слева от k значения False, а справа True, поэтому k = right. Цикл завершается, потому что пока right - left > 1, число mid лежит строго между left и right, и одна из границ каждый раз сдвигается в mid. Расстояние right - left при этом примерно уменьшается вдвое, оно целое и по условию цикла не может стать меньше 1, поэтому цикл конечный. Случай k = 0 тоже работает: если t(0) истинно, то right сдвигается до 0, left остается равным -1, и программа выводит 0.
